# Vehicle Boarding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the player walk into a vehicle's hatch trigger, press Interact to be seated in the cockpit and ride the vehicle, and press Interact again to disembark at an authored exit point without re-boarding.

**Architecture:** Three focused MonoBehaviours. `PlayerRig` (on the player) owns how a player suspends and restores itself. `VehicleBoarding` (on any vehicle root) owns the trigger zone, the Interact input and the board/exit transitions, and reaches the player only through `PlayerRig`'s two-method interface. `BoardingPrompt` (on a Canvas) owns the label. Nothing in `VehicleBoarding` is Dropship-specific, so a car or a static object becomes boardable by adding the component and authoring two child transforms.

**Tech Stack:** Unity 6000.0.76f1, `com.unity.inputsystem` 1.19.0, `com.unity.ugui` 2.0.0 (legacy `UnityEngine.UI.Text`; TextMeshPro is not imported). C# 9, target `v4.7.1`.

**Source spec:** `docs/superpowers/specs/2026-09-01-vehicle-boarding-design.md`

## Global Constraints

- New scripts go in `Assets/objects/`, alongside `PlayerController.cs`, `PlayerCameraControl.cs`, `PlanetGravityBody.cs`, `GravityField.cs`.
- Match the existing house style in that folder: XML `<summary>` doc comment on every public type explaining *why* it exists, `[Tooltip]` on every serialized field, `[Header]` grouping, and `OnDrawGizmos` where authoring a transform by hand needs visual feedback.
- Use `rb.linearVelocity`, never the obsolete `rb.velocity` — `PlayerController.cs` already uses `linearVelocity`.
- Use `FindFirstObjectByType<T>()`, never the obsolete `FindObjectOfType<T>()`.
- Prompt copy is exactly `"Press E to pilot the dropship"` for boarding and `"Press E to exit"` for disembarking, both serialized so other vehicles can override them.
- Do not modify `Assembly-CSharp.csproj` — it is Unity-generated and carries a "do not modify" banner. The build check writes a scratch copy instead.
- Do not hand-write `.cs.meta` files. The running Unity Editor generates them on focus.
- No commit trailers of any kind (no `Co-Authored-By`, no "Generated with").

## Verification approach — read this before starting

This plan does **not** use TDD, which is a deliberate deviation from the default, chosen by the user. The project has no test assembly, and adding a PlayMode test rig would require the Unity Editor to be closed to take the project lock — the editor is currently open. The user chose a compile check as the automated oracle.

Therefore:

- **The per-task automated check is a headless compile** via `tools/build-check.sh`, which must report `0 Error(s)`. This is a real independent check — it catches type errors, obsolete API use, bad signatures and missing references — but it is **not** a behaviour check.
- **Behaviour is verified by the user**, by playtest, against the checklist in Task 5. No task in this plan may be reported as "working" or "verified" on the strength of the compile alone. The honest claim is "compiles clean; behaviour unverified pending playtest."

### Task 1: Build-check script (the oracle)

**Files:**
- Create: `tools/build-check.sh`

**Interfaces:**
- Consumes: nothing.
- Produces: a `tools/build-check.sh` script that every later task runs as its check. It copies `Assembly-CSharp.csproj` to a scratch location, injects `<Compile Include>` entries for every `.cs` file under `Assets/objects/`, and builds that copy with `dotnet build`.

**Why a scratch copy:** Unity regenerates `Assembly-CSharp.csproj` and will not list new files until it next refreshes. Editing the generated file would be overwritten and violates its own banner. Copying it and injecting the file list gives an accurate compile without touching anything Unity owns.

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# Headless compile check for the gameplay scripts in Assets/objects/.
#
# Unity's generated Assembly-CSharp.csproj lists source files explicitly and is
# regenerated by the editor, so we never edit it. Instead we copy it to a scratch
# location and inject a <Compile Include> line for every .cs file under
# Assets/objects/, then build that copy. Catches compile errors without needing
# the Unity Editor to be closed.
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
SRC_CSPROJ="$ROOT/Assembly-CSharp.csproj"
SCRATCH="$ROOT/Temp/build-check"
OUT_CSPROJ="$SCRATCH/BuildCheck.csproj"

[ -f "$SRC_CSPROJ" ] || { echo "ERROR: $SRC_CSPROJ not found. Open the project in Unity once to generate it."; exit 1; }

mkdir -p "$SCRATCH"

# Build the <Compile Include> block: every gameplay script, paths relative to the
# project root (the csproj's own base directory).
COMPILE_LINES=""
while IFS= read -r f; do
  rel="${f#$ROOT/}"
  win_rel="${rel//\//\\}"
  COMPILE_LINES="$COMPILE_LINES    <Compile Include=\"$win_rel\" />"$'\n'
done < <(find "$ROOT/Assets/objects" -name '*.cs' | sort)

# Strip the original <Compile Include> lines, then splice ours into that ItemGroup.
python - "$SRC_CSPROJ" "$OUT_CSPROJ" "$ROOT" <<'PY'
import re, sys
src, out, root = sys.argv[1], sys.argv[2], sys.argv[3]
text = open(src, encoding='utf-8-sig').read()

import subprocess, os
files = []
for dirpath, _, names in os.walk(os.path.join(root, 'Assets', 'objects')):
    for n in sorted(names):
        if n.endswith('.cs'):
            rel = os.path.relpath(os.path.join(dirpath, n), root).replace('/', '\\')
            files.append(rel)

block = '\n'.join('    <Compile Include="%s" />' % f for f in sorted(files))

# Remove every existing Compile Include, then insert our block before the first
# </ItemGroup> that followed them.
text, n = re.subn(r'[ \t]*<Compile Include="[^"]*"[ \t]*/>\r?\n', '', text)
if n == 0:
    raise SystemExit('ERROR: no <Compile Include> entries found in the generated csproj')
text = text.replace('<ItemGroup>', '<ItemGroup>\n' + block + '\n', 1)

# The csproj resolves references relative to itself; pin BaseDirectory to the root.
text = text.replace('<BaseDirectory>.</BaseDirectory>',
                    '<BaseDirectory>%s</BaseDirectory>' % root.replace('/', '\\'))
open(out, 'w', encoding='utf-8').write(text)
print('build-check: compiling %d file(s)' % len(files))
for f in sorted(files):
    print('  ', f)
PY

cd "$ROOT"
dotnet build "$OUT_CSPROJ" -v:q -nologo
```

```csharp
using UnityEngine;
using UnityEngine.UI;

/// <summary>
/// A single on-screen interaction prompt ("Press E to ...").
///
/// Deliberately knows nothing about vehicles, boarding, or the player: it is told what text
/// to show and when to hide, so any interactable in the scene can drive the same label.
/// One of these in the scene is enough — <see cref="VehicleBoarding"/> finds it automatically
/// when its own reference is left empty, so adding a new vehicle needs no UI wiring.
///
/// Uses legacy uGUI <see cref="Text"/> rather than TextMeshPro because TMP's essential
/// resources are not imported in this project; this works with no package import.
/// </summary>
public class BoardingPrompt : MonoBehaviour
{
    [Tooltip("The label to drive. If left empty, the first Text found in this object's " +
             "children (including inactive ones) is used.")]
    public Text label;

    void Awake()
    {
        if (label == null)
            label = GetComponentInChildren<Text>(includeInactive: true);

        Hide(); // never start visible; something must ask for it
    }

    /// <summary>Show the prompt with the given text.</summary>
    public void Show(string message)
    {
        if (label == null)
            return;

        label.text = message;
        label.gameObject.SetActive(true);
    }

    /// <summary>Hide the prompt.</summary>
    public void Hide()
    {
        if (label != null)
            label.gameObject.SetActive(false);
    }
}
```

### Task 3: PlayerRig

**Files:**
- Create: `Assets/objects/PlayerRig.cs`

**Interfaces:**
- Consumes: existing `PlayerController`, `PlanetGravityBody`, `PlayerCameraControl` (all in `Assets/objects/`). Uses `PlayerCameraControl.SetTarget(Transform)`, its public `distance` and `focusHeight` fields, and `SnapBehindPlayer()`. Uses `PlanetGravityBody.GravityUp`.
- Produces:
  - `public bool IsSuspended { get; private set; }`
  - `public Vector3 GravityUp { get; }`
  - `public bool Suspend(Transform seatAnchor, Transform cameraTarget, float camDistance, float camFocusHeight)`
  - `public void Restore(Vector3 position, Quaternion rotation, Vector3 inheritedVelocity)`

  Task 4 calls only `IsSuspended`, `GravityUp`, `Suspend` and `Restore`.

**Two non-obvious details this task must handle:**

1. **Scale compensation.** The Dropship is scaled 1.4172 and the seat anchor inherits that. Parenting the player under it would visibly inflate the player mesh by 1.4172x. `Suspend` records the player's world (lossy) scale before parenting and sets a counter-scaled `localScale` after, so the player's on-screen size is unchanged; `Restore` puts the original `localScale` back.
2. **Ordering around `isKinematic`.** Zero the velocities *before* setting `isKinematic = true`, and set `isKinematic = false` *before* assigning the inherited velocity on restore. Assigning velocity to a kinematic Rigidbody is ignored, which would silently drop the inherited momentum.

- [ ] **Step 1: Write the file**

```csharp
using UnityEngine;

/// <summary>
/// The player's own description of how it suspends and restores itself.
///
/// This exists so that vehicles never have to know what a player is made of. A vehicle calls
/// <see cref="Suspend"/> to seat the player and <see cref="Restore"/> to put them back on
/// their feet; everything about which components to switch off, what to do with the
/// Rigidbody, and where the camera points lives here. Add a component to the player later
/// and only this file changes — no vehicle script is touched.
///
/// While suspended the player is parented to a seat, made kinematic and non-colliding, so it
/// rides its vehicle as one rigid unit while staying visible in the cockpit.
/// </summary>
[RequireComponent(typeof(Rigidbody))]
[DisallowMultipleComponent]
public class PlayerRig : MonoBehaviour
{
    [Header("References (auto-filled from this object when left empty)")]
    [Tooltip("Movement controller, switched off while riding a vehicle.")]
    public PlayerController controller;

    [Tooltip("Gravity receiver, switched off while riding a vehicle so it stops pulling the " +
             "seated player toward the planet.")]
    public PlanetGravityBody gravityBody;

    [Tooltip("The collider that represents the player's body. Disabled while seated so the " +
             "player does not collide with the hull it is sitting inside.")]
    public Collider bodyCollider;

    [Tooltip("The orbit camera. Retargeted to the vehicle while riding, back to the player on " +
             "exit. If left empty, the one in the scene is found automatically.")]
    public PlayerCameraControl cameraControl;

    Rigidbody rb;

    // --- state saved at Suspend, restored at Restore ---
    Transform savedParent;
    Vector3 savedLocalScale;
    bool savedKinematic;
    bool savedColliderEnabled;
    float savedCamDistance;
    float savedCamFocusHeight;

    /// <summary>True while the player is seated in something and not under its own control.</summary>
    public bool IsSuspended { get; private set; }

    /// <summary>
    /// The player's current "up" (planet surface normal), taken from the gravity receiver.
    /// Falls back to the transform's own up when there is no receiver. Keeps working while
    /// suspended, because the receiver holds its last known value when disabled.
    /// </summary>
    public Vector3 GravityUp => gravityBody != null ? gravityBody.GravityUp : transform.up;

    void Awake()
    {
        rb = GetComponent<Rigidbody>();

        if (controller == null)
            controller = GetComponent<PlayerController>();
        if (gravityBody == null)
            gravityBody = GetComponent<PlanetGravityBody>();
        if (bodyCollider == null)
            bodyCollider = GetComponent<Collider>();
        if (cameraControl == null)
            cameraControl = FindFirstObjectByType<PlayerCameraControl>();
    }

    /// <summary>
    /// Seat the player at <paramref name="seatAnchor"/> and hand the camera to
    /// <paramref name="cameraTarget"/>. Returns false (changing nothing) if already suspended
    /// or the seat is missing, so a caller can safely abort.
    /// </summary>
    public bool Suspend(Transform seatAnchor, Transform cameraTarget,
                        float camDistance, float camFocusHeight)
    {
        if (IsSuspended || seatAnchor == null)
            return false;

        savedParent = transform.parent;
        savedLocalScale = transform.localScale;
        savedKinematic = rb.isKinematic;
        savedColliderEnabled = bodyCollider != null && bodyCollider.enabled;

        if (controller != null)
            controller.enabled = false;
        if (gravityBody != null)
            gravityBody.enabled = false;

        // Zero the velocities BEFORE going kinematic: assignments to a kinematic Rigidbody
        // are ignored, so the order matters.
        rb.linearVelocity = Vector3.zero;
        rb.angularVelocity = Vector3.zero;
        rb.isKinematic = true;

        if (bodyCollider != null)
            bodyCollider.enabled = false;

        // The seat may sit under a scaled vehicle (the dropship is ~1.42x). Counter-scale so
        // the player's on-screen size is unchanged by being parented.
        Vector3 worldScale = transform.lossyScale;
        transform.SetParent(seatAnchor, worldPositionStays: false);
        transform.localScale = DivideComponentwise(worldScale, seatAnchor.lossyScale);
        transform.localPosition = Vector3.zero;
        transform.localRotation = Quaternion.identity;

        if (cameraControl != null && cameraTarget != null)
        {
            savedCamDistance = cameraControl.distance;
            savedCamFocusHeight = cameraControl.focusHeight;

            cameraControl.SetTarget(cameraTarget);
            cameraControl.distance = camDistance;
            cameraControl.focusHeight = camFocusHeight;
            cameraControl.SnapBehindPlayer();
        }

        IsSuspended = true;
        return true;
    }

    /// <summary>
    /// Put the player back on its feet at the given world pose, carrying
    /// <paramref name="inheritedVelocity"/> (normally the vehicle's) so stepping off something
    /// moving neither launches nor strands them. No-op when not suspended.
    /// </summary>
    public void Restore(Vector3 position, Quaternion rotation, Vector3 inheritedVelocity)
    {
        if (!IsSuspended)
            return;

        transform.SetParent(savedParent, worldPositionStays: true);
        transform.localScale = savedLocalScale;
        transform.SetPositionAndRotation(position, rotation);

        if (bodyCollider != null)
            bodyCollider.enabled = savedColliderEnabled;

        // Leave kinematic BEFORE assigning velocity, otherwise the assignment is dropped.
        rb.isKinematic = savedKinematic;
        rb.position = position;
        rb.rotation = rotation;
        rb.linearVelocity = inheritedVelocity;
        rb.angularVelocity = Vector3.zero;

        if (gravityBody != null)
            gravityBody.enabled = true;
        if (controller != null)
            controller.enabled = true;

        if (cameraControl != null)
        {
            cameraControl.SetTarget(transform);
            cameraControl.distance = savedCamDistance;
            cameraControl.focusHeight = savedCamFocusHeight;
            cameraControl.SnapBehindPlayer();
        }

        savedParent = null;
        IsSuspended = false;
    }

    /// <summary>Componentwise a/b, leaving a's component untouched where b's is ~0.</summary>
    static Vector3 DivideComponentwise(Vector3 a, Vector3 b)
    {
        return new Vector3(
            Mathf.Approximately(b.x, 0f) ? a.x : a.x / b.x,
            Mathf.Approximately(b.y, 0f) ? a.y : a.y / b.y,
            Mathf.Approximately(b.z, 0f) ? a.z : a.z / b.z);
    }
}
```

### Task 4: VehicleBoarding

**Files:**
- Create: `Assets/objects/VehicleBoarding.cs`

**Interfaces:**
- Consumes: `PlayerRig.IsSuspended`, `PlayerRig.GravityUp`, `PlayerRig.Suspend(Transform, Transform, float, float)`, `PlayerRig.Restore(Vector3, Quaternion, Vector3)` from Task 3; `BoardingPrompt.Show(string)` / `Hide()` from Task 2; `PlanetGravityBody.GravityUp` from the existing code.
- Produces: `public bool IsPiloted { get; private set; }`, `public PlayerRig Pilot { get; private set; }`, `public bool Board(PlayerRig rig)`, `public void Disembark()`. The flight feature will later add a serialized `pilotedController` field enabled/disabled alongside `IsPiloted`.

**The one input listener rule.** There must be exactly one `interactAction.performed` subscription in this file, branching on `IsPiloted`. Two subscriptions — one for boarding and one for exiting — would let a single keypress exit and re-board within the same frame. This is the specific defect the design exists to prevent; do not split it.

- [ ] **Step 1: Write the file**

```csharp
using UnityEngine;
using UnityEngine.InputSystem;

/// <summary>
/// Makes any object boardable: a dropship, a car, a turret, a docked pod.
///
/// Put this on the object's root, give it a trigger collider (the doorway/hatch volume), and
/// author two child transforms — a seat and an exit spot. A player who walks into the trigger
/// is offered a prompt; pressing Interact seats them and hands the camera to this object;
/// pressing Interact again puts them back on their feet at the exit spot.
///
/// Nothing here is ship-specific. The player is reached only through <see cref="PlayerRig"/>'s
/// two-method interface, entrants are detected by component rather than by tag or layer, and
/// the Rigidbody is optional — so a static object is boardable too. Adding a new vehicle is
/// authoring work, not code.
///
/// This step covers boarding, riding and disembarking only; actually flying the vehicle is a
/// separate feature that will add its own controller component and have this script enable it
/// alongside <see cref="IsPiloted"/>.
/// </summary>
[DisallowMultipleComponent]
public class VehicleBoarding : MonoBehaviour
{
    [Header("Anchors (author these as child objects)")]
    [Tooltip("Where the pilot sits. Its ROTATION decides which way the pilot faces.")]
    public Transform seatAnchor;

    [Tooltip("Where the player is placed on exit. Author this OUTSIDE the boarding trigger " +
             "volume and clear of the hull colliders, with its forward pointing away from " +
             "the vehicle — that is what stops a disembark from immediately re-boarding.")]
    public Transform exitPoint;

    [Header("Input")]
    [Tooltip("The 'Interact' action from InputSystem_Actions. One action both boards and exits.")]
    public InputActionReference interactAction;

    [Header("Prompt")]
    [Tooltip("On-screen label. If left empty, the one in the scene is found automatically, so " +
             "a newly added vehicle needs no UI wiring.")]
    public BoardingPrompt prompt;

    [Tooltip("Shown while standing in the trigger, before boarding.")]
    public string boardPrompt = "Press E to pilot the dropship";

    [Tooltip("Shown while piloting.")]
    public string exitPrompt = "Press E to exit";

    [Header("Piloting Camera")]
    [Tooltip("Camera distance while piloting. A big ship wants much more than a walking " +
             "character: ~18 for the dropship, ~8 for a car.")]
    public float pilotCamDistance = 18f;

    [Tooltip("Camera focus height while piloting: ~4 for the dropship, ~1.5 for a car.")]
    public float pilotCamFocusHeight = 4f;

    [Header("Dev Visualization")]
    public bool drawGizmos = true;

    /// <summary>True while a player is seated in this vehicle.</summary>
    public bool IsPiloted { get; private set; }

    /// <summary>The seated player, or null.</summary>
    public PlayerRig Pilot { get; private set; }

    // The rig currently standing in the trigger volume and eligible to board.
    PlayerRig rigInZone;

    Rigidbody vehicleRb;              // optional: only used to hand over momentum on exit
    PlanetGravityBody vehicleGravity; // optional: preferred source of "up" when placing the player

    void Awake()
    {
        vehicleRb = GetComponent<Rigidbody>();
        vehicleGravity = GetComponent<PlanetGravityBody>();

        if (prompt == null)
            prompt = FindFirstObjectByType<BoardingPrompt>();
    }

    void OnEnable()
    {
        InputAction action = interactAction != null ? interactAction.action : null;
        if (action == null)
            return;

        action.Enable();
        action.performed += OnInteract;
    }

    void OnDisable()
    {
        InputAction action = interactAction != null ? interactAction.action : null;
        if (action == null)
            return;

        action.performed -= OnInteract;
    }

    // ---------------------------------------------------------------------
    // Zone detection
    // ---------------------------------------------------------------------

    void OnTriggerEnter(Collider other)
    {
        if (IsPiloted)
            return;

        // Detect by component, not tag or layer: anything with a rig can board anything.
        PlayerRig rig = other.GetComponentInParent<PlayerRig>();
        if (rig == null || rig.IsSuspended)
            return;

        rigInZone = rig;
        ShowPrompt(boardPrompt);
    }

    void OnTriggerExit(Collider other)
    {
        if (rigInZone == null)
            return;

        PlayerRig rig = other.GetComponentInParent<PlayerRig>();
        if (rig != rigInZone)
            return;

        rigInZone = null;
        HidePrompt();
    }

    // ---------------------------------------------------------------------
    // Input — ONE listener, branching on state. See the class comment.
    // ---------------------------------------------------------------------

    void OnInteract(InputAction.CallbackContext _)
    {
        if (IsPiloted)
            Disembark();
        else if (rigInZone != null)
            Board(rigInZone);
    }

    // ---------------------------------------------------------------------
    // Transitions
    // ---------------------------------------------------------------------

    /// <summary>
    /// Seat <paramref name="rig"/> in this vehicle. Returns false and changes nothing when the
    /// vehicle is occupied or its anchors are not authored.
    /// </summary>
    public bool Board(PlayerRig rig)
    {
        if (IsPiloted || rig == null)
            return false;

        if (seatAnchor == null || exitPoint == null)
        {
            Debug.LogError($"{name}: VehicleBoarding needs both seatAnchor and exitPoint " +
                           "assigned before it can be boarded.", this);
            return false;
        }

        if (!rig.Suspend(seatAnchor, transform, pilotCamDistance, pilotCamFocusHeight))
            return false;

        Pilot = rig;
        IsPiloted = true;

        // Disabling the player's collider inside a trigger does not reliably raise
        // OnTriggerExit, so clear the zone flag explicitly rather than trusting physics to.
        rigInZone = null;

        ShowPrompt(exitPrompt);
        return true;
    }

    /// <summary>Put the seated player back on their feet at the exit point. No-op when empty.</summary>
    public void Disembark()
    {
        if (!IsPiloted || Pilot == null)
        {
            IsPiloted = false;
            Pilot = null;
            return;
        }

        PlayerRig rig = Pilot;

        Vector3 up = ExitUp(rig);
        Quaternion rotation = ExitRotation(up, rig);
        Vector3 velocity = vehicleRb != null ? vehicleRb.linearVelocity : Vector3.zero;

        // Clear state before restoring, so anything reacting to the restore sees an empty vehicle.
        IsPiloted = false;
        Pilot = null;
        rigInZone = null;

        rig.Restore(exitPoint.position, rotation, velocity);

        HidePrompt();
    }

    /// <summary>
    /// Surface normal to stand the player up along. Prefers the vehicle's own gravity receiver,
    /// which stays live while piloting, over the player's, which is frozen at its boarding value.
    /// </summary>
    Vector3 ExitUp(PlayerRig rig)
    {
        if (vehicleGravity != null && vehicleGravity.GravityUp.sqrMagnitude > 1e-6f)
            return vehicleGravity.GravityUp.normalized;

        Vector3 rigUp = rig.GravityUp;
        return rigUp.sqrMagnitude > 1e-6f ? rigUp.normalized : exitPoint.up;
    }

    /// <summary>Face the exit point's forward, flattened onto the surface, with a sane fallback.</summary>
    Quaternion ExitRotation(Vector3 up, PlayerRig rig)
    {
        Vector3 forward = Vector3.ProjectOnPlane(exitPoint.forward, up);
        if (forward.sqrMagnitude < 1e-6f)
            forward = Vector3.ProjectOnPlane(transform.forward, up);
        if (forward.sqrMagnitude < 1e-6f)
            return rig.transform.rotation; // exit point points straight up/down; keep facing

        return Quaternion.LookRotation(forward.normalized, up);
    }

    // ---------------------------------------------------------------------
    // Prompt
    // ---------------------------------------------------------------------

    void ShowPrompt(string message)
    {
        if (prompt != null)
            prompt.Show(message);
    }

    void HidePrompt()
    {
        if (prompt != null)
            prompt.Hide();
    }

    // ---------------------------------------------------------------------
    // Authoring aid — the exit point placement is the thing most likely to be wrong.
    // ---------------------------------------------------------------------

    void OnDrawGizmos()
    {
        if (!drawGizmos)
            return;

        if (seatAnchor != null)
        {
            Gizmos.color = new Color(0.3f, 0.9f, 0.5f, 0.9f);
            Gizmos.DrawWireSphere(seatAnchor.position, 0.35f);
            Gizmos.DrawRay(seatAnchor.position, seatAnchor.forward * 1.2f);
        }

        if (exitPoint != null)
        {
```
